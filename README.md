# ЧистоЛист

Приватный веб-комбайн для работы с таблицами, документами, фотографиями и текстом полностью на стороне браузера (**Zero-Server / Local-First**).

**Сайт:** https://chistolist.bond

## Почему без сервера

Файлы пользователей никогда не загружаются в облако: вся обработка (парсинг, перерисовка PDF, удаление EXIF и сравнение текстов) выполняется локально в памяти вкладки браузера.

## Возможности

- **Таблицы (CSV / Excel):** удаление дубликатов и пустых строк, очистка лишних пробелов и невидимых символов, нормализация российских телефонов, разбивка ФИО на 3 колонки, сохранение пользовательских правил и экспорт в `.xlsx` / `.csv` (UTF-8 BOM).
- **Документы (PDF):** необратимое замазывание конфиденциальных данных (растеризация страниц с чёрными блоками), наложение водяных знаков, перестановка, удаление и склейка страниц.
- **Фото и сканы:** просмотр и полное удаление EXIF/GPS-метаданных, сжатие и конвертация (`JPEG`, `WebP`, `PNG`), водяные знаки и сборка изображений в единый PDF.
- **Анонимайзер текста:** локальная замена телефонов, email, паспортов, ИНН, СНИЛС, счетов и стоп-слов на заглушки с обратной расшифровкой.
- **Сравнение редакций (Diff):** построчное и пословное сравнение двух версий текста с подсветкой изменений.

## Стек

- React 19 + TypeScript + Vite
- `xlsx` (SheetJS), `pdf-lib`, `pdfjs-dist`, `lucide-react`

## Локальный запуск

```bash
npm install
npm run dev
```
